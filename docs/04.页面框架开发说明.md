## 一、页面框架概述

### 什么是页面框架？

页面框架是应用的基本结构，定义了整个应用有哪些页面，以及页面之间如何跳转。

```
┌─────────────────────────────────────────┐
│              路由（Router）               │
│         决定显示哪个页面                  │
├────────────┬────────────┬───────────────┤
│   Home     │ Category   │   NotFound    │
│   页面     │  Detail 页面│    页面       │
└────────────┴────────────┴───────────────┘
```

### 我们创建的页面

| 页面 | 路由 | 文件 | 功能 |
|------|------|------|------|
| Home | `/` | `pages/Home.tsx` | 首页：Hero + 分类 + 底部网格 |
| CategoryDetail | `/category/:id` | `pages/CategoryDetail.tsx` | 分类详情页 |
| NotFound | `*` | `pages/NotFound.tsx` | 404 页面 |

## 二、React Router 基础

### 什么是 React Router？

React Router 是 React 的官方路由库，用于实现单页应用（SPA）的页面跳转。

### 核心概念

| 概念 | 说明 | 示例 |
|------|------|------|
| **BrowserRouter** | 路由容器，包裹整个应用 | `<BrowserRouter>...</BrowserRouter>` |
| **Routes** | 路由配置容器 | `<Routes>...</Routes>` |
| **Route** | 单个路由配置 | `<Route path="/" element={<Home />} />` |
| **Link** | 页面链接（不刷新） | `<Link to="/about">关于</Link>` |
| **useParams** | 获取 URL 参数 | `const { id } = useParams()` |

### 路由配置示例

```tsx
// src/App.tsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import { Home } from './pages/Home';
import { CategoryDetail } from './pages/CategoryDetail';
import { NotFound } from './pages/NotFound';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        {/* 首页 */}
        <Route path="/" element={<Home />} />

        {/* 分类详情页，:id 是动态参数 */}
        <Route path="/category/:id" element={<CategoryDetail />} />

        {/* 404 页面，* 匹配所有未匹配的路径 */}
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}
```

### 动态路由

```
/category/hardware     → id = "hardware"
/category/software     → id = "software"
/category/ai           → id = "ai"
```

在 CategoryDetail 页面中获取参数：

```tsx
import { useParams } from 'react-router-dom';

function CategoryDetail() {
  const { id } = useParams<{ id: string }>();
  // id 就是 URL 中的分类 ID
  return <div>当前分类: {id}</div>;
}
```

## 三、Home 页面详解

### 3.1 页面结构

```tsx
export function Home() {
  return (
    <div className="min-h-screen bg-white">
      {/* 1. Hero Section */}
      <section className="...">
        <img src={personal.avatar} alt="头像" />
        <h1>我是 {personal.name}</h1>
        <p>{personal.slogan}</p>
        <Button>了解更多</Button>
      </section>

      {/* 2. 分类区块 */}
      {categories.map(category => (
        <section key={category.id}>
          <img src={category.coverImage} alt={category.name} />
          <h2>{category.name}</h2>
          <p>{category.description}</p>
          <Link to={`/category/${category.id}`}>查看更多</Link>
        </section>
      ))}

      {/* 3. 底部网格 */}
      <section>
        {gridItems.map(item => (
          <Link to={item.link}>{item.title}</Link>
        ))}
      </section>

      {/* 4. Footer */}
      <Footer />
    </div>
  );
}
```

### 3.2 map 遍历列表

使用 `map` 遍历数组生成多个相同的结构：

```tsx
// 遍历分类数组，为每个分类创建一个区块
{categories.map((category) => (
  <section key={category.id}>
    <h2>{category.name}</h2>
    <p>{category.description}</p>
  </section>
))}
```

**注意：** 每个 map 生成的元素都需要唯一的 `key` prop。

### 3.3 Link 组件

```tsx
import { Link } from 'react-router-dom';

// 跳转到分类详情页
<Link to={`/category/${category.id}`}>
  查看更多
</Link>
```

**Link vs a 标签：**
| 特点 | Link | a 标签 |
|------|------|--------|
| 页面刷新 | ❌ 不会刷新 | ✅ 会刷新 |
| SPA 跳转 | ✅ 快速 | ❌ 慢 |
| 历史记录 | ✅ 自动记录 | ❌ 需要手动处理 |

## 四、CategoryDetail 页面详解

### 4.1 页面功能

1. 从 URL 获取分类 ID
2. 找到对应的分类信息
3. 过滤该分类下的所有项目
4. 显示项目列表

### 4.2 完整代码

```tsx
import { useParams, Link } from 'react-router-dom';
import { categories, projects } from '../data';
import { Button } from '../components/Button';
import { Footer } from '../components/Footer';

export function CategoryDetail() {
  // 1. 获取 URL 参数
  const { id } = useParams<{ id: string }>();

  // 2. 查找分类信息
  const category = categories.find((c) => c.id === id);

  // 3. 过滤该项目
  const categoryProjects = projects.filter((p) => p.categoryId === id);

  // 4. 处理分类不存在的情况
  if (!category) {
    return (
      <div>
        <h1>分类不存在</h1>
        <Link to="/"><Button>返回首页</Button></Link>
      </div>
    );
  }

  // 5. 渲染页面
  return (
    <div>
      {/* 返回链接 */}
      <Link to="/">← 返回首页</Link>

      {/* 分类标题 */}
      <h1>{category.name}</h1>
      <p>{category.description}</p>

      {/* 项目列表 */}
      {categoryProjects.map((project) => (
        <div key={project.id}>
          <img src={project.image} alt={project.title} />
          <h3>{project.title}</h3>
          <p>{project.description}</p>
          {/* 技术栈标签 */}
          {project.techStack.map((tech) => (
            <span key={tech}>{tech}</span>
          ))}
        </div>
      ))}

      <Footer />
    </div>
  );
}
```

### 4.3 数组方法

| 方法 | 作用 | 示例 |
|------|------|------|
| **find** | 查找单个元素 | `categories.find(c => c.id === 'hardware')` |
| **filter** | 过滤多个元素 | `projects.filter(p => p.categoryId === 'hardware')` |
| **map** | 遍历转换 | `['a', 'b'].map(x => x.toUpperCase())` |

## 七、常见问题

### Q: 什么是 SPA（单页应用）？
**A:** SPA 是单页应用的缩写，整个应用只有一个 HTML 页面，通过 JavaScript 动态切换内容，用户体验更像原生应用。

### Q: 为什么用 Link 而不是 a？
**A:** Link 不会刷新页面，保持 SPA 的流畅体验。

### Q: 什么是动态路由？
**A:** 路由路径中带有参数，如 `/category/:id`，可以匹配不同的 URL。

### Q: find 和 filter 有什么区别？
**A:** find 返回第一个匹配的元素，filter 返回所有匹配的元素组成的数组。

```typescript
// find - 返回单个对象或 undefined
const category = categories.find(c => c.id === 'hardware');

// filter - 返回数组
const projects = projects.filter(p => p.categoryId === 'hardware');
```

### Q: key 为什么重要？
**A:** React 用 key 来追踪列表中的元素，正确的 key 可以提高渲染性能。

```tsx
// ✅ 正确：使用唯一 ID
{categories.map(c => <div key={c.id}>...</div>)}

// ❌ 错误：使用索引（不推荐，除非列表不会变化）
{categories.map((c, i) => <div key={i}>...</div>)}
```
