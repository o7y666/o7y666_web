# 个人网站开发计划

> 分步开发，每步可验证

---

## 整体流程

```
第1步：初始化项目 → 第2步：创建数据 → 第3步：基础组件 → 第4步：页面开发 → 第5步：样式动画 → 第6步：测试部署
```

---

## 详细步骤

### 第 1 步：初始化项目
**目标**：创建 React + TypeScript + Vite 项目，安装依赖

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 1.1 | 初始化 Vite 项目 | 项目骨架 |
| 1.2 | 安装 Tailwind CSS | 样式配置 |
| 1.3 | 安装 React Router | 路由配置 |
| 1.4 | 安装 Framer Motion | 动画支持 |
| 1.5 | 安装 Lucide React | 图标库 |

**验证方式**：`npm run dev` 能正常启动，显示默认页面

---

### 第 2 步：创建数据文件
**目标**：创建所有数据文件，定义类型

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 2.1 | 创建 `data/personal.ts` | 个人信息数据 |
| 2.2 | 创建 `data/categories.ts` | 分类数据 |
| 2.3 | 创建 `data/projects.ts` | 项目数据 |
| 2.4 | 创建 `data/gridItems.ts` | 底部网格数据 |
| 2.5 | 创建 `data/social.ts` | 社交链接数据 |

**验证方式**：运行 `tsc` 无类型错误

---

### 第 3 步：创建基础组件
**目标**：创建可复用的 UI 组件

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 3.1 | 创建 `Button.tsx` | CTA 按钮组件 |
| 3.2 | 创建 `Footer.tsx` | 页脚组件 |
| 3.3 | 创建 `ScrollToTop.tsx` | 滚动到顶部组件 |

**验证方式**：组件能正常渲染，无报错

---

### 第 4 步：创建页面组件
**目标**：创建各页面框架

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 4.1 | 创建 `App.tsx` + 路由配置 | 主应用入口 |
| 4.2 | 创建 `pages/Home.tsx` | 首页框架 |
| 4.3 | 创建 `pages/CategoryDetail.tsx` | 分类详情页框架 |
| 4.4 | 创建 `pages/NotFound.tsx` | 404 页面 |

**验证方式**：路由正常跳转，页面能显示

---

### 第 5 步：创建核心组件
**目标**：创建页面中的核心组件

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 5.1 | 创建 `Hero.tsx` | Hero 首屏组件 |
| 5.2 | 创建 `CategoryCard.tsx` | 分类卡片组件 |
| 5.3 | 创建 `ProjectCard.tsx` | 项目卡片组件 |
| 5.4 | 创建 `GridCard.tsx` | 底部网格卡片组件 |

**验证方式**：各组件能正确显示数据和图片

---

### 第 6 步：完善页面
**目标**：完善各页面的内容

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 6.1 | 完善 Home 页面 | Hero + 分类卡片 + 底部网格 |
| 6.2 | 完善 CategoryDetail | 返回按钮 + 项目列表 |
| 6.3 | 添加动画效果 | Framer Motion 动画 |

**验证方式**：页面完整显示，动画正常

---

### 第 7 步：样式优化
**目标**：完善样式和响应式

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 7.1 | 配置 Tailwind | 颜色、字体、间距 |
| 7.2 | 添加全局样式 | 平滑滚动、基础重置 |
| 7.3 | 响应式适配 | 手机/平板/桌面适配 |

**验证方式**：在不同尺寸下显示正常

---

### 第 8 步：测试部署
**目标**：测试并部署上线

| 子步骤 | 内容 | 产出 |
|--------|------|------|
| 8.1 | 本地测试 | 修复 Bug |
| 8.2 | 部署到 Vercel | 在线访问 |
| 8.3 | 修复部署问题 | 线上可用 |

**验证方式**：网站能在线访问

---

## 步骤依赖关系

```
第1步（初始化）
    ↓
第2步（数据） → 第3步（基础组件）
    ↓           ↓
第4步（页面框架） ← ← ←
    ↓
第5步（核心组件）
    ↓
第6步（完善页面）
    ↓
第7步（样式优化）
    ↓
第8步（测试部署）
```

---

## 预计总步骤

| 阶段 | 步骤数 | 说明 |
|------|--------|------|
| 初始化 | 5 | 项目搭建 |
| 数据层 | 5 | 数据文件 |
| 组件层 | 3 + 4 = 7 | 基础组件 + 核心组件 |
| 页面层 | 4 | 页面框架 |
| 优化层 | 3 | 样式 + 部署 |
| **总计** | **24 步** | 每步可独立验证 |

---

## 建议节奏

- 每步 5-15 分钟
- 每步完成后本地验证
- 每完成一个阶段提交一次代码
