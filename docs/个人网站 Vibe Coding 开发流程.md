# 个人网站 Vibe Coding 开发流程

> 基于鱼皮的 Vibe Coding 方法论，为个人网站项目定制的完整开发流程

---

## 一、为什么需要标准流程？

在传统编程中，如果对项目规划不清楚，最多就是写出来的代码质量不高，但至少你知道自己在写什么。

但在 Vibe Coding 中，情况就完全不同了。如果对项目规划不清楚，AI 就会"自由发挥"，生成一堆你看不懂、也不需要的代码。

AI 不是魔法，它只是一个非常强大的执行者。你告诉它做什么，它就做什么。如果你自己都不知道要做什么，AI 自然也无法帮你做出理想的产品。

**一套清晰的开发流程可以帮助你：**
1. 明确项目目标和需求
2. 让 AI 理解你的意图
3. 避免项目失控
4. 提高开发效率
5. 做出真正有用的产品

---

## 二、标准 5 步工作流

| 步骤 | 名称 | 产出文件 | 核心目的 |
|------|------|----------|----------|
| 1 | 需求研究 | `RESEARCH.md` | 明确做什么、为什么做 |
| 2 | 产品需求文档 | `PRD.md` | 详细功能定义 |
| 3 | 技术设计文档 | `TECH_DESIGN.md` | 确定技术方案 |
| 4 | AI 代理指令 | `AGENTS.md` | 规范 AI 开发行为 |
| 5 | 实现和迭代 | - | 逐步构建产品 |

---

## 三、针对个人网站项目的具体流程

### 步骤一：需求研究（Research）

**目标**：明确你要做什么，为什么要做，有没有做过类似的东西。

**具体操作**：

1. **明确目标**
   - 问自己：我想解决什么问题？
   - 期望网站是什么样的？
   - 主要展示哪些内容？

2. **调研参考网站**
   - 搜索 "developer portfolio examples"
   - 浏览优秀个人网站找灵感
   - 记录喜欢的设计风格和功能

3. **记录发现**
   - 创建 `RESEARCH.md` 文件
   - 记录目标、调研发现、核心需求

**参考模板**：

```markdown
# 个人网站需求研究

## 目标
做一个简洁现代的个人作品集网站，展示我的能力和项目。

## 调研发现
- 市面上的作品集网站设计风格多样
- 简洁的深色主题很受欢迎
- 项目展示需要包含截图和描述
- 联系方式要清晰可见

## 核心需求
1. 个人介绍（姓名、头像、简介）
2. 技能展示
3. 项目展示
4. 联系方式
5. 响应式设计
```

---

### 步骤二：产品需求文档（PRD）

**目标**：把需求整理成正式文档，明确要做哪些功能，不做哪些功能。

**核心要点**：
- 一份好的 PRD 可以让 AI 准确理解你的意图
- 先自己写简单描述，再让 AI 帮你扩展

**参考模板**：

```markdown
# 个人作品集网站 PRD

## 产品概述
一个简洁现代的个人作品集网站，用于展示个人技能和项目经验。

## 目标用户
- 招聘HR和技术面试官
- 潜在客户和合作伙伴
- 技术社区同行

## 核心功能

### 必须做（MVP）
1. 首页
   - 大标题 + 个人简介
   - 头像
   - 社交媒体链接

2. 关于我
   - 详细介绍
   - 技能列表（可分类展示）

3. 项目展示
   - 项目卡片列表
   - 每个卡片包含：项目名称、项目截图、简短描述、技术栈、项目链接

4. 联系方式
   - 邮箱
   - GitHub 链接
   - 其他社交媒体链接

### 后续可以做
- 深色/浅色主题切换
- 博客功能
- 多语言支持
- 访问统计
- 留言板功能

## 设计要求
- 简洁现代的设计风格
- 深色主题（背景 #0a0a0a，文字 #ffffff）
- 流畅的滚动动画
- 移动端适配
- 图片懒加载优化性能
```

---

### 步骤三：技术设计文档（Tech Design）

**目标**：确定用什么技术来实现，以及项目的大致架构。

**参考模板**：

```markdown
# 个人作品集网站技术设计

## 技术栈
- 前端框架：React + TypeScript + Vite
- 样式方案：Tailwind CSS
- 动画库：Framer Motion
- 路由：React Router（如需多页面）
- 部署平台：Vercel

## 项目结构

src/
  components/          # 可复用组件
    Header.tsx         # 导航栏
    Hero.tsx           # 首页主区域
    About.tsx          # 关于我
    Skills.tsx         # 技能展示
    Projects.tsx       # 项目展示
    Contact.tsx        # 联系方式
    Footer.tsx         # 页脚
    ProjectCard.tsx    # 项目卡片组件

  pages/               # 页面（如果使用多页面）
    Home.tsx
    About.tsx
    Projects.tsx
    Contact.tsx

  data/                # 数据文件
    projects.ts        # 项目数据
    skills.ts          # 技能数据
    social.ts          # 社交链接数据

  hooks/               # 自定义 Hooks
    useScroll.ts       # 滚动相关

  types/               # TypeScript 类型定义
    index.ts

  App.tsx              # 主应用组件
  main.tsx             # 入口文件

## 数据管理
- 项目数据和技能数据存储在 TypeScript 文件中
- 使用数组存储，方便后续添加和修改
- 无需后端，数据静态化

## 关键技术点
1. 使用 Tailwind CSS 实现响应式布局
2. 使用 Framer Motion 添加平滑动画
3. 图片使用懒加载优化性能
4. 确保移动端适配
```

---

### 步骤四：AI 代理指令（AGENTS.md）

**目标**：创建一份给 AI 的"工作手册"，规范 AI 在项目中的开发行为。

**参考模板**：

```markdown
# 个人作品集网站 AI 开发指令

## 项目概述
使用 React + TypeScript + Tailwind CSS 开发的个人作品集网站，展示个人技能和项目经验。

## 开发规范
- 使用函数式组件 + Hooks
- 使用 TypeScript，确保类型安全
- 使用 Tailwind CSS 编写样式
- 组件要可复用、有注释
- 遵循单一职责原则

## 代码风格
- 组件名使用 PascalCase（如 ProjectCard）
- 函数名使用 camelCase（如 handleSubmit）
- 常量使用 UPPER_SNAKE_CASE
- 文件名使用 camelCase（如 heroSection.tsx）

## 设计要求
- 深色主题（背景 #0a0a0a，文字 #ffffff）
- 使用渐变色作为强调色（如紫色、蓝色）
- 添加平滑的滚动动画（Framer Motion）
- 确保移动端适配（响应式设计）
- 保持设计简洁，不要过度设计

## 性能要求
- 图片使用懒加载
- 避免不必要的重新渲染
- 代码分割优化加载速度

## 注意事项
- 保持代码简洁，避免过度设计
- 优先实现核心功能
- 确保所有外部链接可点击
- 测试移动端显示效果
- 每次修改前保存代码版本

## 开发环境
- 操作系统：Windows
- 终端：PowerShell
- 请使用 Windows 兼容的命令
```

### 步骤五：实现和迭代（Build）

**核心原则**：小步迭代，不要一步到位。

#### 分步策略：

**第一步：生成基础框架**

```
请根据 PRD.md、TECH_DESIGN.md 和 AGENTS.md 的要求，
初始化一个 React + TypeScript + Vite 项目，并安装 Tailwind CSS。
```

**第二步：逐步实现核心功能**

1. 创建 Hero 组件（首页主区域）
2. 创建 About 组件（关于我）
3. 创建 Skills 组件（技能展示）
4. 创建 Projects 组件（项目展示）
5. 创建 Contact 组件（联系方式）
6. 创建 Footer 组件（页脚）

**第三步：优化实现细节**

- 性能优化
- 动画效果优化
- 用户体验改进
- 界面美化

## 四、避免 AI 失控的关键技巧

### 1. 项目模块化
把功能尽可能隔离开，每次只让 AI 处理一个模块。

### 2. 限定修改范围
```
仅修改 components/Projects.tsx 文件：
1. 添加项目筛选功能
2. 保持现有的样式和布局
3. 不要改动其他文件
```

### 3. 抽象和复用
如果需要类似的页面，主动告诉 AI：
```
请帮我抽象这个页面为可复用的组件，
让其他页面可以通过传入不同的参数来使用。
```

### 4. 版本控制
每完成一个功能就提交一次：
```bash
git add .
git commit -m "实现 Hero 组件"
```

### 5. 人工控制
AI 陷入循环时：
- 清空上下文重新开始
- 换个角度描述问题
- 手动修改部分代码给 AI 正确方向

### 6. 多元 AI 协作
如果当前 AI 生成的代码有问题，可以把代码复制给其他 AI 模型分析，获取修改建议。

## 五、实战提示词示例

### 初始化项目
```
请根据 PRD.md、TECH_DESIGN.md 和 AGENTS.md 的要求，
初始化一个 React + TypeScript + Vite 项目，并安装 Tailwind CSS 和 Framer Motion。
```

### 创建 Hero 组件
```
创建 Hero 组件，包含大标题、简介和头像。
使用深色主题（背景 #0a0a0a），添加渐变色效果。
确保在移动端显示正常。
```

### 创建项目卡片组件
```
创建 ProjectCard 组件，包含项目截图、标题、描述、技术栈标签和项目链接。
使用 Tailwind CSS 实现卡片样式，添加悬停效果。
```

### 创建项目展示区域
```
创建 Projects 组件，展示项目列表。
使用 Grid 布局实现响应式展示，每行显示 2-3 个项目卡片。
支持移动端适配。
```

## 六、部署上线

1. **推送代码到 GitHub**
   ```bash
   git init
   git add .
   git commit -m "完成个人网站开发"
   git remote add origin <你的仓库地址>
   git push -u origin main
   ```

2. **部署到 Vercel**
   - 登录 [Vercel](https://vercel.com)
   - 导入 GitHub 仓库
   - Vercel 会自动检测项目类型并配置构建命令
   - 点击部署，等待完成
   - 获得网站链接

## 七、扩展思路

完成基础版后，可以继续扩展：

- **主题切换**：添加深色/浅色主题切换功能
- **博客功能**：添加文章列表和文章详情页
- **多语言**：支持中英文切换
- **访问统计**：集成 Google Analytics 或 Vercel Analytics
- **留言功能**：添加简单的留言板或评论系统
- **SEO 优化**：添加 meta 标签和 Open Graph

---

## 八、关键要点总结

1. **规划比代码更重要** - 好的规划让开发更顺利
2. **文档是 AI 的指南针** - PRD 和技术设计文档帮助 AI 理解你的意图
3. **小步迭代不失控** - 一次实现一个功能
4. **模块化是大项目的关键** - 隔离功能，便于维护
5. **版本控制是你的后悔药** - 频繁提交，快速回退
