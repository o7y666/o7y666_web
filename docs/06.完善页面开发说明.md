## 一、为什么需要动画？

### 动画的作用

```
┌─────────────────────────────────────────────────────────────┐
│                     动画的作用                              │
├─────────────────────────────────────────────────────────────┤
│  1. 引导注意力 - 吸引用户注意重要内容                        │
│  2. 提升体验 - 让页面交互更流畅自然                          │
│  3. 反馈交互 - 告诉用户操作是否成功                          │
│  4. 增强品牌 - Apple 风格的动画简洁优雅                      │
└─────────────────────────────────────────────────────────────┘
```

### 动画原则

```
✅ 适度原则
   - 动画时长：0.2-0.5 秒
   - 不要过度使用动画
   - 优先考虑用户体验

❌ 避免过度
   - 不要所有元素都加动画
   - 不要使用花哨的动画效果
   - 不要让动画成为浏览阻碍
```

## 二、Framer Motion 简介

### 什么是 Framer Motion？

Framer Motion 是一个 React 动画库，让创建动画变得简单：

```tsx
// 基础用法
import { motion } from 'framer-motion';

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5 }}
>
  内容
</motion.div>
```

### 核心概念

| 概念 | 说明 | 示例 |
|------|------|------|
| `motion.div` | 带动画的 div | `<motion.div>` |
| `initial` | 初始状态 | `initial={{ opacity: 0 }}` |
| `animate` | 目标状态 | `animate={{ opacity: 1 }}` |
| `transition` | 动画配置 | `transition={{ duration: 0.5 }}` |
| `whileHover` | 悬停状态 | `whileHover={{ scale: 1.05 }}` |
| `whileTap` | 点击状态 | `whileTap={{ scale: 0.95 }}` |

## 三、各组件动画实现

### 3.1 Hero 组件动画

```tsx
// src/components/Hero.tsx
import { motion } from 'framer-motion';

// 动画变体
const fadeInUp = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0 },
};

const staggerContainer = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.2,  // 子元素间隔 0.2 秒
    },
  },
};

export function Hero() {
  return (
    <section>
      <motion.div
        variants={staggerContainer}
        initial="hidden"
        animate="visible"
      >
        <motion.img variants={fadeInUp} />           {/* 头像 */}
        <motion.h1 variants={fadeInUp} />            {/* 标题 */}
        <motion.p variants={fadeInUp} />             {/* Slogan */}
        <motion.div variants={fadeInUp} />           {/* 按钮 */}
      </motion.div>
    </section>
  );
}
```

**效果：** 头像 → 标题 → Slogan → 按钮，依次淡入上滑。

### 3.2 CategorySection 组件动画

```tsx
// src/components/CategorySection.tsx
import { motion } from 'framer-motion';

// 图片从左侧滑入
const fadeInLeft = {
  hidden: { opacity: 0, x: -50 },
  visible: { opacity: 1, x: 0 },
};

// 内容从右侧滑入
const fadeInRight = {
  hidden: { opacity: 0, x: 50 },
  visible: { opacity: 1, x: 0 },
};

export function CategorySection({ category, index }) {
  const isEven = index % 2 === 0;

  return (
    <section>
      <div className={`flex ${!isEven ? 'flex-row-reverse' : ''}`}>
        <motion.div variants={fadeInLeft}>  {/* 图片 */}
          <img src={category.coverImage} />
        </motion.div>
        <motion.div variants={fadeInRight}> {/* 内容 */}
          <h2>{category.name}</h2>
        </motion.div>
      </div>
    </section>
  );
}
```

**效果：** 图片和内容从两侧滑入，偶数索引图片在右。

### 3.3 ProjectCard 组件动画

```tsx
// src/components/ProjectCard.tsx
import { motion } from 'framer-motion';

export function ProjectCard({ project, index }) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 30 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true }}
      transition={{ duration: 0.5, delay: index * 0.1 }}
      whileHover={{ y: -5 }}
    >
      <motion.img whileHover={{ scale: 1.05 }} />
      {/* ... */}
      <motion.a whileHover={{ x: 5 }}>查看详情 →</motion.a>
    </motion.div>
  );
}
```

**效果：** 卡片依次淡入，悬停时上浮，图片放大。

### 3.6 PageTransition 页面过渡

```tsx
// src/components/PageTransition.tsx
import { motion } from 'framer-motion';

const pageVariants = {
  initial: { opacity: 0, x: -20 },
  animate: { opacity: 1, x: 0 },
  exit: { opacity: 0, x: 20 },
};

export function PageTransition({ children }) {
  return (
    <motion.div
      initial="initial"
      animate="animate"
      exit="exit"
      variants={pageVariants}
      transition={{ duration: 0.3 }}
    >
      {children}
    </motion.div>
  );
}
```

**使用方式：**

```tsx
// src/pages/Home.tsx
import { PageTransition } from '../components/PageTransition';

export function Home() {
  return (
    <PageTransition>
      <div>页面内容</div>
    </PageTransition>
  );
}
```

## 四、动画属性详解

### 4.1 常见动画属性

```tsx
// 位置
x: 20              // x 轴位移
y: -20             // y 轴位移

// 透明度
opacity: 0.5       // 透明度 0-1

// 缩放
scale: 1.1         // 缩放比例

// 旋转
rotate: 45         // 旋转角度

// 倾斜
skewX: 10          // x 轴倾斜
```

### 4.2 动画配置

```tsx
transition={{
  duration: 0.5,     // 动画时长（秒）
  delay: 0.2,        // 延迟时间（秒）
  ease: 'easeOut',   // 缓动函数
  repeat: Infinity,  // 重复次数
}}
```

### 4.3 缓动函数

| 函数 | 效果 |
|------|------|
| `easeIn` | 开始慢，中间快 |
| `easeOut` | 开始快，中间慢 |
| `easeInOut` | 开始慢，中间快，结束慢 |
| `linear` | 匀速 |
| `anticipate` | 预加速，Apple 风格 |

### 4.4 视口配置

```tsx
viewport={{
  once: true,           // 只触发一次
  margin: '-100px',     // 视口边距
}}
```

## 六、性能优化

### 6.1 使用 `whileInView`

```tsx
// ✅ 正确：元素进入视口时触发动画
<motion.div whileInView={{ opacity: 1 }} />

// ❌ 错误：每次渲染都会触发动画
<motion.div animate={{ opacity: 1 }} />
```

### 6.2 设置 `once: true`

```tsx
<motion.div
  whileInView={{ opacity: 1 }}
  viewport={{ once: true }}  // 只触发一次
/>
```

### 6.3 使用 `will-change`

```tsx
<motion.div
  style={{ willChange: 'transform, opacity' }}
>
  内容
</motion.div>
```

## 八、常见问题

### Q: 动画太多页面卡顿怎么办？
**A:**
1. 使用 `whileInView` 代替 `animate`
2. 设置 `viewport={{ once: true }}`
3. 减少同时动画的元素数量

### Q: 动画在某些设备上不流畅？
**A:**
1. 避免使用 `filter` 等性能开销大的属性
2. 优先使用 `transform` 和 `opacity`
3. 添加 `will-change` 提示浏览器优化

### Q: 如何禁用动画？
**A:**
```tsx
import { reducedMotion } from 'framer-motion';

const shouldReduceMotion = reducedMotion.matches;

<motion.div
  initial={shouldReduceMotion ? false : { opacity: 0 }}
>
  内容
</motion.div>
```
