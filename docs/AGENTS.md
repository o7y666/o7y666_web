# 个人作品集网站 AI 开发指令

## 项目概述

一个简洁优雅的个人作品集网站，参考 Apple 官网设计风格。

**页面结构**：
- 首页：Hero 首屏（大区块）+ 分类卡片（全宽）+ 底部网格（2x2）
- 分类详情页：展示该分类的所有项目
- 附加页面：关于我、联系方式、技能展示

**设计特点**：
- **全宽通栏布局** - 各区块占满整个屏幕宽度
- **居中对齐** - 标题和文字居中显示
- **大图为主** - 分类以封面图为视觉焦点
- **CTA 按钮** - 蓝色填充按钮 + 蓝色文字链接
- **2x2 底部网格** - 并列展示次要内容
- **浅色系** - 白色背景 + 苹果蓝强调色

## 开发规范

- 使用函数式组件 + Hooks
- 使用 TypeScript，确保类型安全
- 使用 Tailwind CSS 编写样式
- 使用 React Router 实现页面路由
- 组件要可复用、有注释
- 遵循单一职责原则

## 代码风格

- 组件名使用 PascalCase（如 `ProjectCard`、`CategoryCard`）
- 函数名使用 camelCase（如 `handleSubmit`）
- 常量使用 UPPER_SNAKE_CASE
- 文件名使用 camelCase（如 `heroSection.tsx`）
- CSS 类名使用 kebab-case

## 设计要求

### 配色方案（Apple 风格浅色系）

| 元素 | 颜色 | Tailwind 类 |
|------|------|-------------|
| 强调色 | 苹果蓝 #007AFF | `text-[#007AFF]` / `bg-[#007AFF]` |
| 背景色 | 纯白 #FFFFFF | `bg-white` |
| 次要背景 | 浅灰 #F5F5F7 | `bg-[#F5F5F7]` |
| 主要文字 | 深灰 #1D1D1F | `text-[#1D1D1F]` |
| 次要文字 | 浅灰 #86868b | `text-[#86868b]` |

### 区块尺寸规范

| 区块 | 高度 | 说明 |
|------|------|------|
| Hero 首屏 | 60-80vh | 最大，首屏视觉焦点 |
| CategoryCard | 300-400px | 全宽，图片为主 |
| GridCard | 200-300px | 2x2 网格，等高 |
| ProjectCard | 自适应 | 详情页使用 |

### CTA 按钮规范

```typescript
// 主按钮（蓝色填充）
<button className="bg-[#007AFF] text-white rounded-full px-6 py-2">
  了解更多
</button>

// 副按钮（蓝色文字）
<button className="text-[#007AFF] hover:underline">
  了解更多
</button>
```

### 组件要求

**Hero 组件**：
- 高度要大（60-80vh），比分类区块更醒目
- 居中布局，大字号
- 包含：头像、姓名、slogan
- **包含两组 CTA 按钮**：蓝色填充 + 蓝色文字链接

**CategoryCard 组件**：
- **全宽通栏布局**
- 以封面图片为主要视觉元素（占区块大部分面积）
- 标题居中显示
- **CTA 按钮组**：蓝色填充 + 蓝色链接
- **整个卡片可点击**，链接到 `/category/:id`
- 悬停时有放大或蒙层效果

**GridCard 组件**：
- 2x2 网格布局中的卡片
- 白色或浅灰背景
- 居中标题 + 简短描述
- 可点击，链接到指定页面

**CategoryDetail 页面**：
- 根据 URL 参数 `:id` 获取分类信息
- 展示该分类的所有项目
- 包含返回首页链接

## 动画效果（Framer Motion）

- 滚动进入视口时的淡入效果（Fade In）
- 卡片悬停时的缩放效果（Scale 1.02）
- 平滑滚动（Smooth Scroll）
- 页面加载动画

## 性能要求

- 图片使用懒加载
- 避免不必要的重新渲染
- 代码分割优化加载速度

## 注意事项

- 保持代码简洁，避免过度设计
- 优先实现核心功能
- 确保所有外部链接可点击
- 测试移动端显示效果
- 每次修改前保存代码版本
- 不要修改未指定的文件
- 新分类/新网格项只需修改数据文件，无需新建组件
- 保持居中对齐的设计风格

## 路由结构

| 路径 | 页面 |
|------|------|
| `/` | Home（首页） |
| `/category/:id` | CategoryDetail（分类详情页） |
| `/about` | About（关于我） |
| `/contact` | Contact（联系方式） |
| `/skills` | Skills（技能展示） |
| `*` | NotFound（404） |

## 数据文件结构

```
src/data/
  categories.ts    # 分类数据（id, name, coverImage, description）
  projects.ts      # 项目数据（categoryId 关联分类）
  gridItems.ts     # 底部网格数据（2x2 布局）
  personal.ts      # 个人信息
  social.ts        # 社交链接
```
