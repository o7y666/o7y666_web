## 一、什么是数据层？

### 数据层的定义

在网页应用中，**数据层**是存储和管理应用数据的地方。

```
┌─────────────────────────────────────────┐
│              页面组件（UI）               │
│         负责显示数据、响应用户交互          │
├─────────────────────────────────────────┤
│              数据层（Data）               │
│         存储所有应用需要的数据              │
├─────────────────────────────────────────┤
│              后端服务（可选）              │
│         从服务器获取或保存数据              │
└─────────────────────────────────────────┘
```

### 为什么需要数据层？

| 好处 | 说明 |
|------|------|
| **数据集中管理** | 所有数据在一个地方，方便维护 |
| **便于修改** | 改数据不用改代码 |
| **组件复用** | 同一份数据可以被多个组件使用 |
| **易于扩展** | 新功能只需添加数据，不用大改代码 |

## 三、类型定义（types.ts）

### 什么是 TypeScript 类型？

TypeScript 的类型系统可以描述数据的"形状"。

```typescript
// 定义一个"人"的类型
interface Person {
  name: string;      // 姓名（字符串）
  age: number;       // 年龄（数字）
  isStudent: boolean; // 是否是学生（布尔值）
}

// 使用类型
const person: Person = {
  name: '张三',
  age: 25,
  isStudent: false,
};
```

### 为什么要先定义类型？

1. **自动补全** - 编辑器知道有哪些字段
2. **错误检查** - 用错类型会报错
3. **代码可读** - 一看就知道数据结构

### 我们定义的所有类型

```typescript
// types.ts

// 分类数据类型
export interface Category {
  id: string;           // 唯一标识（如 'hardware'）
  name: string;         // 显示名称（如 '硬件设计'）
  description?: string; // 描述（可选，加 ?）
  coverImage: string;   // 封面图地址（必填）
  buttonText?: string;  // 按钮文字（可选）
}

// 项目数据类型
export interface Project {
  id: string;           // 唯一标识
  categoryId: string;   // 关联的分类 ID
  title: string;        // 项目标题
  description: string;  // 一句话描述
  image: string;        // 项目截图
  techStack: string[];  // 技术栈（数组）
  link: string;         // 项目链接
  github?: string;      // GitHub 链接（可选）
  featured?: boolean;   // 是否精选（可选）
}

// 底部网格数据类型
export interface GridItem {
  id: string;
  title: string;
  description?: string;
  image?: string;
  link: string;
  icon: string;         // 图标名称
}

// 个人信息类型
export interface PersonalInfo {
  name: string;
  avatar: string;
  slogan: string;
  bio: string;
  email: string;
}

// 社交链接类型
export interface SocialLink {
  id: string;
  name: string;
  url: string;
  icon: string;
}
```

### 类型说明

| 符号 | 含义 | 示例 |
|------|------|------|
| `string` | 字符串 | `"hello"` |
| `number` | 数字 | `123` |
| `boolean` | 布尔值 | `true` / `false` |
| `string[]` | 字符串数组 | `["React", "TypeScript"]` |
| `?` | 可选属性 | `description?: string` |

## 四、数据文件详解

### 4.1 分类数据（categories.ts）

```typescript
import type { Category } from './types';

export const categories: Category[] = [
  {
    id: 'hardware',
    name: '硬件设计',
    description: '电路设计、PCB设计、嵌入式系统',
    coverImage: 'https://images.unsplash.com/...',
  },
  // ...更多分类
];
```

**关键点：**
- `import type { Category }` - 从 types.ts 导入类型
- `: Category[]` - 声明这是 Category 类型的数组
- `export const` - 导出供其他文件使用

### 4.2 项目数据（projects.ts）

```typescript
import type { Project } from './types';

export const projects: Project[] = [
  {
    id: 'hw-1',

    title: 'STM32 嵌入式系统',
    description: '基于 STM32 的嵌入式系统设计',
    image: 'https://images.unsplash.com/...',
    techStack: ['STM32', 'C语言', 'PCB'],
    link: '#',
  },
  // ...更多项目
];
```

**关键点：**
- `categoryId: 'hardware'` - 关联到分类的 `id`
- `techStack: ['STM32', 'C语言']` - 数组类型
- 所有字段类型要匹配 types.ts 的定义

## 五、统一导出（index.ts）

### 什么是导出？

在 TypeScript/Node.js 中，使用 `export` 让其他文件可以使用这些数据。

### 统一导出的好处

```typescript
// index.ts

// 方法 1：分别导入
import { categories } from './categories';
import { projects } from './projects';

// 方法 2：统一导入（推荐）
import { categories, projects, gridItems, socialLinks, personal } from './data';
```

### 我们的 index.ts

```typescript
export { categories } from './categories';
export { projects } from './projects';
export { gridItems } from './gridItems';
export { socialLinks } from './social';
export { personal } from './personal';

export type { Category, Project, GridItem, PersonalInfo, SocialLink } from './types';
```

**好处：**
- 导入时只需要 `import { categories, projects } from '@/data'`
- 不用关心数据存在哪个文件

## 六、使用数据

### 在组件中使用

```tsx
// Home.tsx
import { categories, projects, personal } from '@/data';

function Home() {
  return (
    <div>
      <h1>{personal.name}</h1>  {/* 显示姓名 */}
      <p>{personal.slogan}</p>   {/* 显示 slogan */}

      {categories.map(cat => (    {/* 遍历分类 */}
        <div key={cat.id}>
          <h2>{cat.name}</h2>
        </div>
      ))}
    </div>
  );
}
```

## 八、常见问题

### Q: 为什么要用 TypeScript 类型？
**A:** 类型检查可以在开发时发现错误，比如拼错字段名、用错类型。

### Q: 数据放在文件里安全吗？
**A:** 这是前端数据，任何人都能看到。不放敏感信息（如密码）。

### Q: 怎么添加新数据？
**A:** 在对应文件添加新对象即可。

```typescript
// 添加新分类
export const categories: Category[] = [
  // 现有分类...
  {
    id: 'new-category',
    name: '新分类',
    coverImage: '/images/new.jpg',
  },
];
```

### Q: 什么是 `import type`？
**A:** 只导入类型定义，不导入实际值，编译后会被移除。
