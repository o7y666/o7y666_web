# 个人作品集网站 PRD

## 产品概述

一个简洁优雅的个人作品集网站，参考 Apple 官网设计风格，展示硬件工程师的多元化作品（硬件设计、软件学习、AI 应用）。

**一句话简介**：一个展示多元技能和作品的个人网站，像苹果官网一样简洁优雅。

## 目标用户

- 招聘 HR 和技术面试官
- 潜在合作伙伴和客户
- 技术社区同行
- 对硬件/软件/AI 感兴趣的人

---

## 设计理念

### Apple 官网风格核心特点

- **全宽通栏布局**：各区块占满整个屏幕宽度
- **大量留白**：呼吸感十足的视觉空间
- **居中对齐**：标题和文字居中显示
- **大图为主**：产品/分类以大图为视觉焦点
- **CTA 按钮**：蓝色填充按钮 + 蓝色文字链接
- **2x2 网格**：底部并列展示次要内容
- **优雅动效**：平滑的滚动动画和过渡
- **浅色系**：清爽明亮的视觉体验

### 区块层级设计

| 层级 | 区块 | 说明 |
|------|------|------|
| 1 | Hero 首屏 | 最大，60-80vh 高度，视觉突出 |
| 2 | 分类区块 | 全宽，300-400px 高度，图片为主 |
| 3 | 底部网格 | 2x2 并列，等分布局 |
| 4 | 分类详情页 | 点击分类后的项目详细列表 |

## 核心功能

### MVP（必须做）

#### 1. Hero 首屏（大区块）
- 个人头像（圆形/方形）
- 大标题："我是 XXX"
- Slogan：一句话介绍自己
- **CTA 按钮**：
  - 主按钮：蓝色填充（"了解更多"）
  - 副按钮：蓝色文字链接
- **视觉上比其他区块更大**（60-80vh 高度）
- **居中对齐**

#### 2. 分类区块（可点击进入详情）

**设计规范**：
- 全宽通栏布局
- 大图封面为主（占区块大部分面积）
- 标题居中显示在图片上方或下方
- 简短描述（可选）
- **CTA 按钮**：蓝色填充 + 蓝色链接
- **点击整个卡片进入详情页**

**分类内容**：

| 分类 | 内容 |
|------|------|
| 硬件设计 | 电路设计、PCB设计、嵌入式系统等 |
| 软件学习 | 操作系统、App应用、工具软件等 |
| AI 应用 | AI 工具使用心得、应用实践等 |
| 探索中 | 后续拓展的新领域 |

#### 3. 底部网格区域（2x2）

| 区块 | 内容 | 说明 |
|------|------|------|
| 关于我 | 个人详细介绍 | 点击跳转到关于我页面 |
| 联系方式 | 邮箱、社交媒体 | 点击复制邮箱或跳转 |
| 技能展示 | 技能标签云 | 展示主要技能 |
| 其他 | 预留扩展 | 后续添加 |

#### 4. 分类详情页

每个分类点击后进入独立页面，展示该分类下的所有项目：

| 页面 | 内容 |
|------|------|
| 硬件设计详情页 | 该分类所有项目的卡片列表 |
| 软件学习详情页 | 该分类所有项目的卡片列表 |
| AI 应用详情页 | 该分类所有项目的卡片列表 |
| 探索中详情页 | 该分类所有项目的卡片列表 |

#### 5. 项目卡片（详情页内）

每个卡片包含：
- 项目截图/封面图
- 项目名称
- 一句话描述
- 技术栈标签
- 项目链接

#### 6. 页脚

- 联系方式（邮箱、GitHub、LinkedIn）
- 版权信息
- 社交媒体链接

## 设计要求

### 配色方案（浅色系 - Apple 风格）

| 元素 | 颜色 | 说明 |
|------|------|------|
| 主色调 | 白色 #FFFFFF、浅灰 #F5F5F7 | 大面积使用 |
| 强调色 | 蓝色 #007AFF | 按钮、链接 |
| 背景色 | 纯白 #FFFFFF | 页面背景 |
| 文字色 | 深灰 #1D1D1F | 主要文字 |
| 辅助色 | 浅灰 #86868b | 次要文字 |
| 卡片背景 | 白色 #FFFFFF | 可选卡片背景 |

### 字体排版

- **字体**：SF Pro / 苹方 / Inter / 系统默认
- **对齐**：居中对齐
- **层级**：
  - 一级标题：大字号，加粗
  - Slogan：中字号，简洁有力
  - 说明文字：小字号，浅灰色

### CTA 按钮规范

| 类型 | 样式 | 示例 |
|------|------|------|
| 主按钮 | 蓝色填充，白色文字 | `bg-[#007AFF] text-white` |
| 副按钮 | 蓝色文字，无背景 | `text-[#007AFF] hover:underline` |

### 动画效果

- 滚动进入视口时的淡入效果（Fade In）
- 卡片悬停时的缩放效果（Scale）
- 平滑滚动（Smooth Scroll）
- 页面加载动画（Loading）

### 响应式设计

| 断点 | 布局 |
|------|------|
| 桌面（1024px+） | 全宽通栏，2x2 网格 |
| 平板（768-1024px） | 全宽通栏，2x2 变 1x2 |
| 手机（<768px） | 全宽单列堆叠 |
