# 个人作品集网站 PRD

## 产品概述

一个简洁优雅的个人作品集网站，参考 Apple 官网设计风格，展示硬件工程师的多元化作品（硬件设计、软件学习、AI 应用）。

**一句话简介**：一个展示多元技能和作品的个人网站，像苹果官网一样简洁优雅。

## 目标用户

- 招聘 HR 和技术面试官
- 潜在合作伙伴和客户
- 技术社区同行
- 对硬件/软件/AI 感兴趣的人

---

## 设计理念

### Apple 官网风格

- **沉浸式首屏**：简洁有力的个人介绍
- **分类展示**：按领域分区展示作品
- **大量留白**：呼吸感十足的视觉空间
- **优雅动效**：平滑的滚动动画和过渡
- **浅色系**：清爽明亮的视觉体验

### 网站结构

```

├─────────────────────────────────────────┤

├─────────────────────────────────────────┤
```

### 区块层级设计

| 层级 | 区块 | 说明 |
|------|------|------|
| 1 | Hero 首屏 | 最大，视觉突出，个人介绍 |

## 核心功能

### MVP（必须做）

#### 1. Hero 首屏（大区块）
- 个人头像（圆形/方形）
- 大标题："我是 XXX"
- Slogan：一句话介绍自己
- CTA 按钮：滚动到项目区域
- **视觉上比其他区块更大更醒目**

#### 2. 分类区块（可点击进入详情）

**分类一：硬件设计**
- 大图 + 分类标题
- 简短描述（可选）
- **点击进入该分类的详情页**

**分类二：软件学习**
- 大图 + 分类标题
- 简短描述（可选）
- **点击进入该分类的详情页**

**分类三：AI 应用**
- 大图 + 分类标题
- 简短描述（可选）
- **点击进入该分类的详情页**

**分类四：探索中**（后续拓展）
- 大图 + 分类标题
- 简短描述（可选）
- **点击进入该分类的详情页**

#### 3. 分类详情页

每个分类点击后进入独立页面，展示该分类下的所有项目：

| 页面 | 内容 |
|------|------|
| 硬件设计详情页 | 该分类所有项目的完整列表（卡片形式） |
| 软件学习详情页 | 该分类所有项目的完整列表（卡片形式） |
| AI 应用详情页 | 该分类所有项目的完整列表（卡片形式） |

#### 4. 项目卡片（详情页内）

每个卡片包含：
- 项目名称
- 项目截图/封面图
- 一句话描述
- 技术栈标签
- 项目链接

#### 5. 页脚
- 联系方式（邮箱）
- 社交媒体链接（GitHub、LinkedIn等）
- 版权信息

## 设计要求

## 扩展性考虑

### 数据驱动设计

所有分类和项目数据存储在 JSON/TS 数据文件中，后续添加新分类只需更新数据文件，无需修改组件代码：

```typescript
// categories.ts
export const categories = [
  { id: 'hardware', name: '硬件设计', icon: '...' },
  { id: 'software', name: '软件学习', icon: '...' },
  { id: 'ai', name: 'AI 应用', icon: '...' },
  { id: 'exploring', name: '探索中', icon: '...' },
];

// projects.ts
export const projects = [
  { id: '1', categoryId: 'hardware', title: '...', ... },
  { id: '2', categoryId: 'software', title: '...', ... },
  // 新增项目只需添加到这里
];
```

### 组件化设计

- 每个分类使用相同的卡片组件
- 新分类自动获得一致的展示样式
- 降低维护成本，保证视觉一致性
