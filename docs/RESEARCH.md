> 记录 AI 探索之旅的手绘风格个人网站

---

## 1. 项目目标

### 1.1 核心定位
**AI 学习记录与分享平台**

一个温暖、有趣的手绘风格网站，用于记录和分享 o7y666 在 AI 领域的探索历程。网站不仅是项目展示窗口，更是一个学习日志，见证从 AI 新手到熟练应用者的成长过程。

### 1.2 目标用户
| 用户类型 | 需求 | 网站价值 |
|---------|------|----------|
| **AI 初学者** | 想了解如何入门 AI | 看到真实的学习路径和经验 |
| **同行探索者** | 寻找灵感和方法 | 获取项目思路和工具使用技巧 |
| **潜在合作者** | 了解 o7y666 的能力 | 通过项目质量判断技术水平 |
| **未来的自己** | 回顾学习历程 | 记录成长轨迹，见证进步 |

### 1.3 成功标准
- [ ] 能够清晰展示至少 3 个 AI 项目
- [ ] 每个项目都有完整的故事（背景→过程→成果）
- [ ] 网站本身成为"用 AI 做网站"的示范案例
- [ ] 风格独特，让人记住"那个手绘风格的 AI 探索者"

## 3. 设计风格

### 3.1 整体感觉
**温暖 · 有趣 · 手绘 · 创意**

像一个充满好奇心的探险家的笔记本，记录着 AI 世界的奇妙发现。

### 3.2 视觉风格

#### 参考风格
- **MotherDuck** 品牌设计（温暖配色 + 现代简洁）
- **手绘元素**（不规则边框、轻微旋转、涂鸦感）

#### 配色方案
| 用途 | 颜色 | HEX |
|-----|------|-----|
| 主背景 | 米白/奶油色 | `#F5F5F0` |
| 强调色 | 金黄色 | `#FFD700` |
| 主文字 | 深灰 | `#1A1A1A` |
| 次要文字 | 中灰 | `#666666` |
| AI 深色区块 | 深蓝黑 | `#1E1E2E` |
| 装饰青 | 青色 | `#4ECDC4` |

#### 字体选择
| 用途 | 字体 | 特点 |
|-----|------|------|
| 大标题 | **Caveat** | 流畅手写感，亲切 |
| 正文 | **Patrick Hand** | 清晰可读的手写体 |
| 标签/代码 | **JetBrains Mono** | 等宽字体，科技感 |

## 4. 页面结构

### 4.1 网站地图

```
首页 (Home)
├── Hero - 首屏大标题 + 简介
├── About - 关于我
└── Projects - 项目列表（卡片网格）
    └── 点击卡片进入项目详情页

项目详情页 (Project Detail)
├── 项目标题 + 返回按钮
├── 项目封面/演示
├── 项目故事
├── 技术要点
└── GitHub 链接

关于页 (About) - 可选
├── 详细介绍
├── 学习历程时间线
└── 联系方式
```

### 4.2 核心区块设计

#### Hero 区块
- **大标题**：手写风格 "o7y666"
- **副标题**："AI 技术探索者"
- **一句话**："记录用 AI 创造的过程"
- **CTA 按钮**："查看项目" / "了解更多"
- **装饰**：云朵、小吉祥物、几何图形

#### About 区块
- **标题**："关于我" 或 "我是谁"
- **头像**：手绘边框包裹的虚拟头像（先用 AI 生成一个）
- **简介**：2-3 段个人故事
- **GitHub 链接**： prominently displayed

#### Projects 区块
- **标题**："我的项目" 或 "AI 实验室"
- **副标题**："用 AI 创造的一些东西"
- **项目卡片网格**：
  - 封面图（项目截图/演示 GIF）
  - 项目名称
  - 一句话描述
  - 使用的 AI 工具标签
  - "查看详情" 按钮

## 5. 技术考量

### 5.1 技术栈（由 AI 辅助选择）
由于是非程序员背景，技术选型以"易维护、AI友好"为原则：

| 层级 | 推荐技术 | 原因 |
|-----|---------|------|
| 框架 | React + TypeScript | AI 生成代码质量高，社区资源多 |
| 样式 | Tailwind CSS | 工具类简单直观，AI 擅长生成 |
| 动画 | Framer Motion | React 生态，AI 示例丰富 |
| 路由 | React Router | 多页面导航 |
| 部署 | Vercel | 一键部署，免费好用 |

### 5.2 不需要复杂功能
- ❌ 不需要后端/数据库（纯静态网站）
- ❌ 不需要用户登录
- ❌ 不需要评论系统
- ❌ 不需要 CMS 后台

### 5.3 需要关注的点
- ✅ 项目详情页的路由配置
- ✅ 视频/GIF 的加载优化
- ✅ GitHub 链接的正确性
- ✅ 移动端显示效果
