## 一、设计理念

### 核心参考：Apple 官网风格

Apple 官网的设计特点：
- **沉浸式首屏**：大图/视频背景，简洁有力的标题
- **分类展示**：按不同领域/类别分区展示内容
- **大量留白**：呼吸感十足的视觉空间
- **优雅动效**：平滑的滚动动画和过渡
- **清晰层次**：从主到次的视觉引导

### 网站结构规划

```
┌─────────────────────────────────────┐
│        首屏：个人简介 + 头像          │
│    "一句话slogan + 姓名 + CTA"      │
├─────────────────────────────────────┤
│        分类一：前端项目               │
│    "全宽大图/卡片 + 项目名称"         │
├─────────────────────────────────────┤
│        分类二：后端项目               │
│    "全宽大图/卡片 + 项目名称"         │
├─────────────────────────────────────┤
│        分类三：设计/其他              │
│    "全宽大图/卡片 + 项目名称"         │
├─────────────────────────────────────┤
│        页脚：联系方式                 │
└─────────────────────────────────────┘
```
