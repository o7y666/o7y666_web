## 一、什么是组件？

### 组件的定义

在 React 中，**组件**是独立的功能模块，可以重复使用。

```
页面 = Header + Hero + CategoryCard + CategoryCard + ... + Footer
```

### 组件的特点

| 特点 | 说明 |
|------|------|
| **可复用** | 一个组件可以在多个地方使用 |
| **可组合** | 组件可以包含其他组件 |
| **独立** | 每个组件有自己的逻辑和样式 |
| **可维护** | 修改一个组件不影响其他部分 |

### 组件的分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **基础组件** | 简单的 UI 元素 | Button、Footer |
| **功能组件** | 有特定功能的组件 | ScrollToTop |
| **页面组件** | 整个页面的组件 | Home、CategoryDetail |

## 三、Button 组件详解

### 3.1 组件代码

```tsx
// src/components/Button.tsx
import { ReactNode } from 'react';

interface ButtonProps {
  variant?: 'primary' | 'secondary';
  children: ReactNode;
  onClick?: () => void;
  className?: string;
  type?: 'button' | 'submit' | 'reset';
  disabled?: boolean;
}

export function Button({
  variant = 'primary',
  children,
  onClick,
  className = '',
  type = 'button',
  disabled = false,
}: ButtonProps) {
  const baseStyles = `
    inline-flex items-center justify-center
    px-6 py-3
    text-base font-medium
    rounded-full
    transition-all duration-200
    focus:outline-none focus:ring-2 focus:ring-offset-2
    disabled:opacity-50 disabled:cursor-not-allowed
  `;

  const variantStyles = {
    primary: 'bg-[#007AFF] text-white hover:bg-[#0066d6] focus:ring-[#007AFF]',
    secondary: 'text-[#007AFF] hover:underline focus:ring-[#007AFF]',
  };

  return (
    <button
      type={type}
      onClick={onClick}
      disabled={disabled}
      className={`${baseStyles} ${variantStyles[variant]} ${className}`}
    >
      {children}
    </button>
  );
}
```

### 3.2 组件说明

**Props（属性）：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| variant | 'primary' \| 'secondary' | 'primary' | 按钮样式 |
| children | ReactNode | - | 按钮内容 |
| onClick | () => void | - | 点击事件 |
| className | string | '' | 额外样式 |
| type | 'button' \| 'submit' \| 'reset' | 'button' | 按钮类型 |
| disabled | boolean | false | 是否禁用 |

**使用示例：**

```tsx
// 主按钮（蓝色填充）
<Button variant="primary">了解更多</Button>

// 副按钮（蓝色文字）
<Button variant="secondary">了解更多</Button>

// 带点击事件
<Button onClick={() => alert('点击了!')}>点击我</Button>

// 禁用状态
<Button disabled>不可点击</Button>
```

### 3.3 组件设计思路

**为什么这样设计？**

1. **两种变体**：满足 Apple 官网风格（蓝色填充 + 蓝色文字）
2. **Tailwind 组合**：用字符串拼接组合样式
3. **默认值**：设置合理的默认值，减少使用时的代码

## 四、Footer 组件详解

### 4.1 组件代码

```tsx
// src/components/Footer.tsx
import { Github, Linkedin, Mail } from 'lucide-react';
import { socialLinks } from '../data';

export function Footer() {
  const currentYear = new Date().getFullYear();

  const getIcon = (iconName: string) => {
    const icons: Record<string, React.ReactNode> = {
      Github: <Github size={20} />,
      Linkedin: <Linkedin size={20} />,
      Mail: <Mail size={20} />,
    };
    return icons[iconName] || null;
  };

  return (
    <footer className="bg-[#F5F5F7] py-12">
      <div className="max-w-6xl mx-auto px-6">
        <div className="flex justify-center gap-6 mb-8">
          {socialLinks.map((link) => (
            <a
              key={link.id}
              href={link.url}
              target="_blank"
              rel="noopener noreferrer"
              className="text-[#86868b] hover:text-[#007AFF] transition-colors duration-200"
              aria-label={link.name}
            >
              {getIcon(link.icon)}
            </a>
          ))}
        </div>
        <div className="text-center text-sm text-[#86868b]">
          <p>© {currentYear} o7y666. All rights reserved.</p>
        </div>
      </div>
    </footer>
  );
}
```

### 4.2 组件说明

**功能：**
- 显示社交媒体链接图标
- 链接到 GitHub、LinkedIn、邮箱
- 显示版权信息（自动获取当前年份）

**技术点：**

| 技术点 | 说明 |
|--------|------|
| **动态图标** | 根据 icon 名称显示对应图标 |
| **map 遍历** | 从数据中遍历生成链接 |
| **时间动态获取** | `new Date().getFullYear()` |

**使用的数据：**
```typescript
// socialLinks 数据
[
  { id: 'github', name: 'GitHub', url: '...', icon: 'Github' },
  { id: 'linkedin', name: 'LinkedIn', url: '...', icon: 'Linkedin' },
  { id: 'email', name: 'Email', url: '...', icon: 'Mail' },
]
```

## 五、ScrollToTop 组件详解

### 5.1 组件代码

```tsx
// src/components/ScrollToTop.tsx
import { useEffect, useState } from 'react';
import { ArrowUp } from 'lucide-react';

export function ScrollToTop() {
  const [isVisible, setIsVisible] = useState(false);

  useEffect(() => {
    const toggleVisibility = () => {
      if (window.scrollY > 400) {
        setIsVisible(true);
      } else {
        setIsVisible(false);
      }
    };

    window.addEventListener('scroll', toggleVisibility);
    return () => window.removeEventListener('scroll', toggleVisibility);
  }, []);

  const scrollToTop = () => {
    window.scrollTo({
      top: 0,
      behavior: 'smooth',
    });
  };

  return (
    <button
      onClick={scrollToTop}
      className={`
        fixed bottom-8 right-8
        w-10 h-10
        bg-[#007AFF] text-white
        rounded-full
        flex items-center justify-center
        shadow-lg
        transition-all duration-300
        hover:bg-[#0066d6] hover:scale-110
        focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-[#007AFF]
        ${isVisible ? 'opacity-100 translate-y-0' : 'opacity-0 translate-y-10 pointer-events-none'}
      `}
      aria-label="滚动到顶部"
    >
      <ArrowUp size={20} />
    </button>
  );
}
```

### 5.2 组件说明

**功能：**
- 滚动超过 400px 后显示按钮
- 点击按钮平滑滚动到页面顶部
- 悬停时有放大效果

**React Hooks：**

| Hook | 用途 |
|------|------|
| **useState** | 控制按钮的显示/隐藏状态 |
| **useEffect** | 监听滚动事件 |

**useState：**
```typescript
const [isVisible, setIsVisible] = useState(false);
// isVisible - 当前是否显示
// setIsVisible - 修改显示状态的函数
```

**useEffect：**
```typescript
useEffect(() => {
  // 注册滚动事件监听
  window.addEventListener('scroll', toggleVisibility);

  // 组件卸载时清理
  return () => window.removeEventListener('scroll', toggleVisibility);
}, []);
```

**条件样式：**
```typescript
className={`
  ${isVisible ? 'opacity-100 translate-y-0' : 'opacity-0 translate-y-10 pointer-events-none'}
`}
// 显示时：完全不透明，位置正常
// 隐藏时：完全透明，位置下移，点击穿透
```

## 六、组件设计原则

### 6.1 单一职责

每个组件只做一件事：

```
✅ 好：Button 只负责按钮样式和点击
❌ 坏：Button 既负责按钮又负责导航逻辑
```

### 6.2 Props 设计

| 原则 | 说明 |
|------|------|
| **合理的默认值** | 减少使用时的必填参数 |
| **明确的类型** | 每个 Props 都有类型定义 |
| **可扩展** | 通过 className 允许自定义样式 |

### 6.3 样式组织

| 方式 | 示例 | 适用场景 |
|------|------|----------|
| **Tailwind 类名** | `className="px-6 py-3"` | 简单组件 |
| **CSS Modules** | `styles.button` | 复杂样式 |
| **CSS-in-JS** | `styled.div` | 需要动态样式 |

## 七、常见问题

### Q: 组件文件为什么要用 .tsx 后缀？
**A:** .tsx 表示 TypeScript + JSX，可以同时使用 TypeScript 类型和 JSX 语法。

### Q: 什么是 ReactNode？
**A:** ReactNode 是 React 中任何可以渲染的内容（字符串、数字、元素、数组等）。

### Q: interface 和 type 有什么区别？
**A:** 都可以定义类型，interface 更适合对象类型，type 更灵活。

```typescript
// interface
interface ButtonProps {
  variant: 'primary' | 'secondary';
}

// type
type ButtonProps = {
  variant: 'primary' | 'secondary';
};
```

### Q: 为什么要用 useEffect？
**A:** useEffect 用于处理副作用，如订阅事件、请求数据、定时器等。

### Q: 什么是 cleanup 函数？
**A:** useEffect 返回的函数，在组件卸载时执行，用于清理副作用。

```typescript
useEffect(() => {
  window.addEventListener('scroll', handler);
  // 组件卸载时，移除事件监听
  return () => window.removeEventListener('scroll', handler);
}, []);
```
