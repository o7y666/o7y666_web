## 二、部署到 Vercel

### 2.1 通过 GitHub 部署（推荐）

```
步骤：
1. 访问 https://vercel.com
2. 点击 "Add New..." → "Project"
3. 选择导入 GitHub 仓库 o7y666/o7y666_web
4. 点击 "Import"
5. Vercel 会自动检测配置：
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
6. 点击 "Deploy"
```

### 2.2 通过 Vercel CLI 部署

```bash
# 安装 Vercel CLI
npm i -g vercel

# 登录 Vercel
vercel login

# 部署到预览环境
vercel

# 部署到生产环境
vercel --prod
```

### 2.3 手动部署

```bash
# 1. 构建项目
npm run build

# 2. 上传 dist 文件夹到服务器
#    可以使用 FTP、SCP 或其他工具

# 3. 配置服务器指向 dist 文件夹
```

## 三、部署配置

### 3.1 Vercel 配置文件

```json
// vercel.json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        { "key": "X-Content-Type-Options", "value": "nosniff" },
        { "key": "X-Frame-Options", "value": "DENY" }
      ]
    }
  ]
}
```

### 3.2 域名配置

```
自定义域名设置：
1. 在 Vercel 项目设置中添加域名
2. 在域名提供商处配置 DNS：
   - A 记录：76.76.21.21
   - CNAME：cname.vercel-dns.com
```

## 四、持续部署

### 4.1 GitHub Actions 自动部署

```yaml
# .github/workflows/deploy.yml
name: Deploy to Vercel

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: amondnet/vercel-action@v25
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.ORG_ID }}
          vercel-project-id: ${{ secrets.PROJECT_ID }}
```

### 4.2 配置步骤

```
1. 生成 Vercel Token：
   - 访问 https://vercel.com/account/tokens
   - 点击 "Create Token"

2. 在 GitHub 仓库设置中添加 secrets：
   - VERCEL_TOKEN
   - ORG_ID（从 Vercel 设置获取）
   - PROJECT_ID（从 Vercel 设置获取）
```

## 五、部署后检查

### 5.1 验证部署成功

```bash
# 访问部署的 URL，检查以下内容：
# 1. 页面正常加载
# 2. 所有链接正常工作
# 3. 动画效果正常
# 4. 移动端布局正常
```

### 5.2 常见问题

| 问题 | 解决方案 |
|------|----------|
| 页面 404 | 检查路由配置，Vercel 需要 rewrites |
| 静态资源加载失败 | 检查输出目录配置 |
| 动画不流畅 | 检查是否启用了生产模式 |
