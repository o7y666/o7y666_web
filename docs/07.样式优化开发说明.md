## 二、按钮组件优化

### 2.1 添加缩放动画

```tsx
// src/components/Button.tsx
import { motion } from 'framer-motion';

// 为 primary 按钮添加动画
if (variant === 'primary') {
  return (
    <motion.div
      whileHover={!disabled ? { scale: 1.02 } : undefined}
      whileTap={!disabled ? { scale: 0.98 } : undefined}
      transition={{ duration: 0.15 }}
    >
      <button>...</button>
    </motion.div>
  );
}
```

**效果：** 主按钮悬停时放大 2%，点击时缩小 2%。

```

功能:
├── 联系信息卡片（邮箱、位置、社交链接）

### 3.2 关于页面 (About)

```
访问路径: /about

功能:
├── 个人简介卡片（头像、名称、简介）

```tsx
// src/pages/About.tsx
export function About() {
  return (
    <PageTransition>

          </div>

        {/* 技能标签 */}

          {skills.map((skill) => (
            <motion.span whileHover={{ scale: 1.05 }}>

        </div>

        <div className="space-y-4">

            <div className="flex items-center gap-4">
              <span className="font-bold text-[#007AFF]">{item.year}</span>
              <span>{item.event}</span>
            </div>
          ))}
        </div>
      </div>
    </PageTransition>
  );

```

### 3.3 技能展示页面 (Skills)

```
访问路径: /skills

功能:
├── 6 个技能分类卡片
│   ├── 硬件设计（PCB、电路、嵌入式）
│   ├── 软件开发（React、TypeScript）
│   ├── 设计工具（Figma）
│   ├── 开发工具（Git、Docker）
│   ├── AI 应用（提示工程）
│   └── 其他技能（项目管理）
├── 技能进度条
└── 技能说明图例
```

```tsx
// src/pages/Skills.tsx
interface SkillCategory {
  name: string;
  icon: React.ReactNode;
  skills: { name: string; level: string }[];
  color: string;
}

const skillCategories: SkillCategory[] = [
  {
    name: '硬件设计',
    icon: <Cpu size={32} />,
    color: '#FF9500',
    skills: [
      { name: 'PCB 设计', level: '熟练' },
      { name: '电路分析', level: '熟练' },
    ],
  },
  // ...
];

export function Skills() {
  return (
    <PageTransition>
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
        {skillCategories.map((category) => (
          <motion.div
            initial={{ opacity: 0, y: 30 }}
            animate={{ opacity: 1, y: 0 }}
          >
            <div className="flex items-center gap-3 mb-6">
              <div style={{ backgroundColor: category.color }}>
                {category.icon}
              </div>
              <h2>{category.name}</h2>
            </div>

            {/* 技能进度条 */}
            {category.skills.map((skill) => (
              <div>
                <div className="flex justify-between">
                  <span>{skill.name}</span>
                  <span>{skill.level}</span>
                </div>
                <div className="h-2 bg-[#F5F5F7] rounded-full">
                  <motion.div
                    className={`h-full rounded-full ${getLevelColor(skill.level)}`}
                    initial={{ width: 0 }}
                    animate={{ width: skill.level === '熟练' ? '80%' : '50%' }}
                  />
                </div>
              </div>
            ))}
          </motion.div>
        ))}
      </div>
    </PageTransition>
  );
}
```

## 四、路由配置

### 4.1 更新后的路由

```tsx
// src/App.tsx
function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/category/:id" element={<CategoryDetail />} />
        <Route path="/contact" element={<Contact />} />
        <Route path="/about" element={<About />} />
        <Route path="/skills" element={<Skills />} />
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}
```

### 4.2 路由对应关系

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | Home | 首页 |
| `/category/:id` | CategoryDetail | 分类详情 |
| `/contact` | Contact | 联系页面（新建） |
| `/about` | About | 关于页面（新建） |
| `/skills` | Skills | 技能展示（新建） |
